# Type(Of)
Coding project in Visual Studio, using Windows forms, .Net 8, read from a JSON file.

A small speed typing game with 3 difficulties, oriented around programmer and programming topics.
The game's main feature is it's difficulty, specifically the Advanced difficulty, for it's coding speed typing challenge.
Other features include: a unique visual style, a previous attempts tracker that displays the stats of the attempts or runs.

*The Previous attempts tracker resets on every new build of the game*

##To run the game:
- Download .exe file 
OR
- Download code -> download ZIP
- Extract in a folder or anywhere
- Run TypeOf.sln and build the app
